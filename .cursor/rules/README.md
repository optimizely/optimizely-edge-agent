# Revised MCP Rules

This directory contains enhanced versions of the core MCP rules, optimized for AI agent comprehension and efficient implementation while maintaining the spirit and depth of the original rules.

## Key Improvements

1. **Visual Decision Flows**: Added flowcharts and decision trees to clarify rule application
2. **Code Examples**: Each rule now includes concrete code examples demonstrating proper implementation
3. **Structured Format**: Consistent structure with clear sections for different scenarios
4. **Explicit Tool Usage**: Clearer guidance on which MCP tools to use for specific purposes
5. **Error Recovery**: Added protocols for handling errors and unexpected situations
6. **Implementation Patterns**: Practical patterns for common implementation scenarios

## Rules in this Directory

- **agent-custom-instructions.md** - Core instructions for AI agents with streamlined workflow protocol
- **component-protection-adherence.mdc** - Rules for respecting component protection levels
- **mcp-interaction-protocol.mdc** - Protocol for MCP server interaction with sequenced steps
- **mcp-operational-workflow.mdc** - Standard workflow for implementing features
- **mcp-server-api-design.mdc** - Guidelines for designing and implementing RESTful APIs
- **mcp-server-dev-protocol.mdc** - Architecture and implementation patterns for server components
- **mcp-server-testing-guideline.mdc** - Comprehensive testing strategies and patterns
- **scope-boundary-enforcement.mdc** - Guidelines for enforcing scope boundaries

## Usage Guidance

These revised rules maintain all essential information from the original rules while providing:

1. **More Structured Implementation Flow**: Clear sequence of steps for implementation
2. **Decision-Making Guidance**: Explicit decision paths for different scenarios
3. **Practical Examples**: Real-world code examples for better understanding
4. **Contextual Tool Usage**: When and how to use specific MCP tools
5. **Visual Aids**: Flowcharts and diagrams for complex processes

AI agents should continue to follow the core principles of the MCP framework, including:
- Checking state, plan, and tasks
- Verifying scope and protection before modifications
- Getting relevant rules for specific files
- Following the implementation workflow
- Providing detailed evidence and status updates
